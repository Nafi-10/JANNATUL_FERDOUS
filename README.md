# Jannatul Ferdous Portfolio

A personal portfolio website built with React, TypeScript, and Vite. The supplied portfolio images are included in the repository.

## Run locally

**Prerequisite:** Node.js

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production site is generated in `dist/`.

## Deploy to Netlify

The included `netlify.toml` configures the production build command and publish directory. To deploy, import this GitHub repository in Netlify and use the detected settings:

- Build command: `npm run build`
- Publish directory: `dist`
